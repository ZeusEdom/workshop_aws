Throughout the 8-week **FCAJ (First Cloud Journey)** program at AWS Vietnam, I actively participated in technical training sessions, mentorship meetings, and community contributions:

---

### 1. Technical Workshops & Mentorship Sessions

- **FCAJ Kick-off & Orientation:** Program onboarding event introducing Amazon Culture (Leadership Principles) and the 8-week internship roadmap.
- **AWS Solutions Architecture Deep-Dive:** Architecture technical sessions led by AWS Solutions Architects covering Serverless design patterns, IAM security best practices, and cloud cost optimization.
- **Hands-on Technical Labs:** Applied lab exercises on Amazon DynamoDB, AWS Lambda, API Gateway, and Infrastructure as Code (IaC).
- **1-on-1 Mentorship Sessions:** Periodic 1-on-1 sessions with AWS Mentors to review project architecture, overcome technical hurdles (such as Python `Decimal` serialization in DynamoDB), and receive Cloud Engineer career advice.

---

### 2. Community & Open-Source Contributions

- **AWS Study Group Participation:** Engaged in technical discussions within the AWS Study Group FCJ community, collaborating with fellow interns.
- **Open-Source GitHub Repository:** Published the public repository [AWS Final Weather Dashboard](https://github.com/ZeusEdom/aws_final) containing all Lambda Python scripts, IAM policies, frontend HTML/JS, and deployment documentation.
- **FCJ Workshop Site Authoring:** Built a step-by-step hands-on workshop guide with 29 console screenshots allowing anyone to replicate the serverless weather architecture.
