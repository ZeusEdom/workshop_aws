The 8-week internship program at **AWS Vietnam** under **FCAJ** provided an invaluable learning experience, enhancing both my technical depth and professional engineering skills.

---

### 1. Hard Technical Skills Gained

- **Mastery of Serverless Architecture:** Deep understanding of event-driven serverless design patterns, seamlessly integrating DynamoDB, Lambda, API Gateway, S3, and EventBridge into a production-grade system.
- **Cloud Security & IAM Governance:** Applying the Principle of Least Privilege by authoring granular IAM Inline Policies and S3 Bucket Policies restricted to exact resource ARNs.
- **Data Lifecycle Automation:** Utilizing DynamoDB TTL to automate record expiration without compute overhead, alongside EventBridge cron scheduling.
- **Troubleshooting & Problem Solving:** Successfully resolving real-world engineering issues, such as Python `boto3` `Decimal` type serialization, custom JSON Encoders, and API Gateway CORS setup.
- **Version Control & Documentation:** Maintaining professional open-source repositories on GitHub and building structured documentation sites using Hugo.
